# TradeEdge

**Track your trades. Find your edge.**

A privacy-first, zero-backend CFD trading journal for Forex, Gold, Crypto, Stock CFDs and Index CFDs.

## What it includes
- Dashboard with P&L, win rate, profit factor, expectancy and drawdown
- Manual trade journal with setup, risk, psychology and mistakes
- Before/after chart screenshots
- Strategy, instrument, session, timeframe, direction and setup-quality analytics
- Automatic descriptive insights
- Demo data mode
- JSON backup/restore and CSV export
- IndexedDB local storage — no account, server or database

## Run
Open `index.html` directly in a browser, or publish the repository with GitHub Pages.

## GitHub Pages
Create a repository named `tradeedge`, upload `index.html` and `README.md`, then enable **Settings → Pages → Deploy from a branch → main / root**. Your site will be available at `https://YOUR-USERNAME.github.io/tradeedge/`.

## Privacy
Trades and screenshots are stored in the browser's IndexedDB. They are not uploaded anywhere by TradeEdge. Export a JSON backup before clearing browser/site data or moving devices.
